# Документація СмакПлану

СмакПлан створює рецепт і список покупок у Сільпо за побажанням, кількістю
людей та бюджетом. Це персональне локальне демо без збереження історії й checkout.

| Документ                       | Що описує                                                        |
| ------------------------------ | ---------------------------------------------------------------- |
| [Архітектура](architecture.md) | Межі модулів, потік даних, бюджет і оптимізація                  |
| [Розробка](development.md)     | Запуск, інструменти, тести та діагностика                        |
| [API](api.md)                  | HTTP-контракти, статуси, обробка помилок                         |
| [Інтеграції](integrations.md)  | OpenAI, Silpo MCP, OAuth, нормалізація товарів                   |
| [Безпека](security.md)         | Секрети, повноваження агента, недовірені дані й залишкові ризики |

[AGENTS.md](../AGENTS.md) містить інструкції для агентів розробки;
[README](../README.md) — короткий опис для запуску застосунку.

Джерела істини: [package.json](../package.json) для команд і залежностей,
[contracts.ts](../src/lib/contracts.ts) для типів і схем,
реалізація відповідного модуля для поведінки. Оновлюйте документацію одночасно
зі змінами контрактів, обмежень або інтеграцій. Зовнішні схеми не вважайте
стабільними лише тому, що вони колись пройшли live-перевірку.
